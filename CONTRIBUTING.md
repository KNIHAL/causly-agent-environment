# Contributing to agenv

Thanks for wanting to contribute! This repo covers two things:

- **`website/`** — the documentation site (Docusaurus) for every Causly Agent Environment product
- **Landing page** (everything else at the repo root) — the public `agenv.causly.in` site

## Docs contributions

Found something outdated, unclear, or missing in the docs? PRs are welcome. Docs for each product
live under `website/docs/<product>/`.

## Landing page contributions

Improvements to the landing page (bug fixes, small UX/copy improvements) are welcome too. For
larger design changes, please open an issue first to discuss before submitting a PR.

## How to submit a change

1. Fork the repo and create a branch off `master`
2. Make your change
3. Run `npm run build` at the repo root to make sure everything still builds cleanly
4. Open a pull request describing what changed and why

## Reporting bugs or suggesting features

Please open an issue using the relevant template under Issues.
