# Security Policy

This repository is a static landing page and documentation site (Next.js + Docusaurus) — there is
no backend, database, or user data processing here.

## Reporting a Vulnerability

If you find a security issue (e.g. an XSS vector, a broken dependency with a known CVE, or a
misconfigured deployment), please report it privately rather than opening a public issue.

**Contact:** nihal@causly.in

We'll acknowledge your report and work with you on a fix and disclosure timeline.
